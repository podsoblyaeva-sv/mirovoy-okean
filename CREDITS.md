- Контуры суши: [Natural Earth](https://www.naturalearthdata.com/), public domain, данные 1:110 млн; [GeoJSON](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson).
- D3 7.9.0, copyright Mike Bostock, лицензия ISC. [Исходный проект](https://github.com/d3/d3).
- Three.js, copyright Three.js Authors, лицензия MIT. [Исходный проект](https://github.com/mrdoob/three.js). Использована локальная библиотека из предыдущего проекта «Гидросфера».
- Исправление классификации Жёлтого моря: [Большая российская энциклопедия](https://old.bigenc.ru/geography/text/2625289).
- Уточнение связи Татарского пролива с Охотским морем: [Татарский пролив](https://ru.wikipedia.org/wiki/Татарский_пролив).
